# 🚀 Luka's Playground — Developer Portfolio

사용자 경험(UX)과 비즈니스 가치를 극대화하는 **풀스택 개발자 Luka**의 기술 포트폴리오 레포지토리입니다.  
웹 서비스 개발 경험과 고도화된 **AI 기반 개발 워크플로우(AI-Driven Development)**를 접목하여 빠른 배포와 높은 코드 품질을 지향합니다.

## 💡 Web Development & AI Experience (핵심 역량 및 AI 활용)

### 1. 실무 중심 웹 서비스 구축 및 풀스택 개발 경험
- **프론트엔드 UI/UX**: React, Next.js, Vanilla JS 기반의 반응형 인터페이스와 데이터 시각화(Chart.js) 구현
- **백엔드 API & DB 설계**: Node.js(Express) 및 PHP(CodeIgniter)를 활용한 RESTful API 구축, MySQL/MongoDB 트랜잭션 및 스키마 최적화
- **실무 결제 & 연동**: NicePay/KCP PG 정기 및 배치 결제 연동, 크롬 익스텐션(MV3) 개발, npm 패키지 배포 경험 보유

### 2. AI 활용 개발 워크플로우 (AI-Assisted Engineering)
본 포트폴리오와 수록된 주요 프로젝트들은 **AI 코딩 어시스턴트(Claude, ChatGPT, Copilot 등)**를 적극적으로 도입하여 제작되었습니다.
- **Rapid Prototyping**: AI 프롬프트 설계를 통해 아이디어를 신속하게 코드 구조로 형상화하고 아키텍처 검증
- **코드 품질 & 리팩토링**: AI 모듈 기반 코드 검수, 크로스 브라우저/반응형 스타일 검증, 예외 처리 강화
- **AI 연동 모듈 개발**: `AIKit` 프로젝트를 통해 AI API 및 자동화 툴킷을 패키지화하여 모듈성 확보
